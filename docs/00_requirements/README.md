## 使用规则

1. Word 原件是排版和签审版本；Markdown 是等价检索副本，不替代原件签审。
2. 图片统一放在 `assets/`，Markdown 使用仓库相对路径引用。
3. 同一事项出现冲突时，优先执行 `docs/02_architecture/DECISIONS.md` 中已冻结的 ADR；未冻结冲突必须进入 P0 开放问题，禁止静默选边。
4. “7 日计划”是带前置条件的冲刺方案，不等同于无条件承诺七天完成双端商店上线。
5. 新版本使用新版本号，不覆盖既有版本；过期版本移动到后续建立的归档目录。
