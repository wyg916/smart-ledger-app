# Android 内部测试计划

范围：API 36 模拟器做安装/路由/回归；至少两种 Android 版本真机做候选包验收，其中号码登录设备必须插 SIM 并启用蜂窝网络。

- 安装与升级：全新安装、旧 Schema 4 升级安装、versionCode、签名一致性、数据保留。
- 认证：无登录不可进入、返回/深链不可绕过、号码和微信成功/取消/异常、审核账号、refresh/logout。
- 隔离：A 写入、退出、B 不可见、A 重登恢复；绑定/全新选择幂等。
- 核心：交易、预算、统计、自然语言、Kimi 对话/图片、Telemetry、应用锁、离线 7 日规则。
- 删除：保留本地与删除本地两条路径、幂等和失败恢复。
- 稳定性：冷启动、后台恢复、预览隐藏，无 FATAL/ANR/数据库异常，日志不含身份或 token。

每条记录设备型号、Android/API、包 SHA-256、时间、测试人、结果、日志路径和缺陷链接。Fake Provider 结果只算工程回归，不替代真实认证。
