# 智能记账隐私政策（工程草案，未完成法律审核）

版本：2026-08-04 草案。发布前必须补齐运营主体、注册地址、`<SUPPORT_EMAIL>`、生效日期、未成年人条款及法律审核结论。

## 处理范围

- 账号登录：本机号码认证由腾讯云/运营商处理；服务端仅保存规范化手机号的带密钥哈希和脱敏提示。微信登录由微信 OpenSDK 发起，授权 code/token 不写日志，服务端只保存 openid/unionid 的带密钥哈希。
- 本地账本：账单、账户、分类和预算按登录用户保存在设备独立 SQLite 文件，不做业务云同步。
- AI：用户主动提交的聚合财务摘要、文字或图片会发送至 Kimi API；图片在服务端内存重编码，不进入运营分析。
- 运营分析：installation/session ID、白名单事件、App 版本和平台发送至自有 FastAPI/PostgreSQL，可与已登录 `user_id` 关联；不采集账单金额、备注、商户、图片或 AI 正文。
- 安全：Access/Refresh Token 存在系统 Secure Storage；生物识别由 Android 系统验证，App 不读取生物特征。
- 网络信息：服务端及认证 SDK 可能为安全、风控和传输处理 IP、运营商、SIM/网络状态、设备型号；OAID 等字段以最终腾讯 SDK 实测清单为准。

## 权限与共享

当前 Manifest 仅声明 Internet 和生物识别权限。微信、腾讯号码认证、Kimi 仅在对应功能所需范围接收数据，不出售个人信息。正式号码认证专属 SDK 接入后必须重新扫描权限、组件、域名和实际采集字段，并更新本草案。

## 保留、删除与权利

用户可在“账号与安全 → 注销账号”二次确认。确认后撤销会话、删除认证身份、解除运营身份映射，并选择删除或隔离保留本地账本。必要的去标识化安全审计仅按适用法律期限保留。公开说明位于 `https://www.znjz.site/account-deletion`。

本草案不代表已部署、已获同意或已完成法律审核。
