## 共同视觉语言

- 主色：珊瑚；背景：暖奶油；辅助色：薄荷、蜂蜜黄、浅天蓝；正文：深可可。
- 卡片 20–24px 圆角，页面左右留白约 16px，卡间距 8–12px；阴影很轻，以边框为主。
- 标题粗而克制；金额比标签大 1–2 个字号层级；正负号和收入/支出文字同时表达方向。
- 主按钮为高 52–56px 的珊瑚圆角按钮；次按钮使用描边或浅色底。
- 输入框浅纸白、16px 圆角；错误在字段下方显示明确文本。
- 图标为圆角 Material 风格，放在柔和彩色容器中；原创零钱精灵只用于欢迎和空状态。
- 空状态需要下一步动作；错误状态保留用户已输入内容；离线状态明确本地功能仍可用。
