## 字体层级

- 页面标题 24/700；区块标题 18/700；金额主值 28–36/800；卡片金额 18–22/700。
- 正文 15/400，辅助 13/400，按钮 16/700。金额使用等宽数字特性（平台支持时）。
- 文案短句优先，避免依赖省略号隐藏金额、风险或错误。

## 组件规则

- `LedgerShell` 负责五项底栏和居中记账入口；二级页面使用普通返回导航。
- `MoneySummaryCard` 永远同时给出标签、币种/符号与整数来源金额的格式化值。
- `CategoryShortcutGrid` 为 3×2 快捷分类加“全部分类”，图标容器 44，点击区至少 64。
- `PeriodSwitcher` 用 segmented control 表达日/月或今天/月度，箭头只用于前后日期/月。
- `TransactionDayGroup` 头部显示日期、星期与日收支；子项保持 56–64 高。
- `AiDraftCard` 和 `ImageAnalysisCard` 明示“待确认”；确认/取消为两个独立操作。
- 错误、离线和空状态使用统一 `LedgerStateCard`，不展示异常堆栈或上游正文。

## 图表

收入为薄荷、支出为珊瑚；趋势图必须有文字图例。排行使用最大值归一化的水平条，零值不除零。
日视图不伪造连续月趋势；月视图继续展示按账本时区补齐的每日点。预算只显示月度进度。
