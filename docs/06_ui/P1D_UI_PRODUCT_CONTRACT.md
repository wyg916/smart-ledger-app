# P1D Rapid UI 产品契约

状态：冻结用于 `P1D-RAPID-UPGRADE`
日期：2026-08-04

## 范围与事实源

本契约以 `docs/05_ai/ui_references/` 中可读取的四张参考板为视觉事实源。需求指定的
`docs/06_ui/reference/` 在基线中不存在；为避免重复提交二进制图片，本轮不复制文件，
在 `UI_REFERENCE_INVENTORY.md` 中建立可审计映射。旧 Android 仅作为交互事实源，新代码
继续写入 `apps/mobile/`。

## 信息架构

底部五项固定为：`首页｜明细｜记一笔｜统计｜AI`。记一笔使用居中突出入口；账户、分类、
预算、游客身份、数据安全和设置从首页头像进入“游客与数据安全”页。详情、编辑、预算等
二级页不显示底栏。

- 首页默认“今天”，可切换今天/本月；首屏依次为问候与游客入口、今日收支净额、智能
  记账输入、六个快捷支出分类、本月预算进度、最近账单和 AI 入口。
- 明细默认当前月，按账本 IANA 时区的当地日期分组；每组显示日期、星期、日收入、日支出
  和交易。支持月份、账户、分类、收入/支出类型筛选及快速回到今天。
- 记一笔保留支出/收入/转账；收支状态直接展示六个快捷分类和“全部分类”。输入金额后点
  快捷分类可立即完成手动记账；自然语言入口只形成待确认草稿。
- 统计明确分为按天/按月。日视图展示所选日收支净额、分类和账单；月视图保留现有趋势、
  排行、账户和预算入口。预算仍只使用月度口径。
- AI 为自由对话主页面，保留月度总结、预算解读、财务规划三个快捷问题；支持文本、截图、
  停止、重试和新会话。

## 日/月规则

- 所有日期边界由账本 `time_zone_id` 计算，使用 `[start, end)` 半开 UTC 区间。
- “今天”是账本时区当地日，不使用服务器时区，也不把月预算折算为日预算。
- 月视图继续按 `LedgerMonth`；日分组由交易 UTC 时间转换到账本 IANA 时区。
- 明细筛选和汇总共用同一查询边界；transfer 不进入收入、支出或净额。

## 快捷分类

- 支出和收入分别返回最多六个启用分类；第七入口为“全部分类”。
- 无历史时按系统 `sort_order`；有历史时按最近 90 天使用次数降序、最近使用时间降序、
  `sort_order`、UUID 排序。时间窗口按账本时区的当前当地日回溯。
- 停用或 Tombstone 分类排除；最近一次成功保存会自然进入数据库排序，不维护重复副本，
  不自动创建分类。

## 视觉与组件

视觉 token 以 `UI_DESIGN_SYSTEM.md` 为准。页面只使用共享色板、8pt 间距、16/22px 圆角、
轻边框和最多一层柔和阴影。金额是首要视觉层级；数据卡与操作卡分离。公共组件至少包括
`LedgerShell`、金额摘要卡、月份/日期切换、分类图标、状态卡、空/错/离线状态和确认草稿卡。

## 响应式与无障碍

- 目标宽度 320–600dp；内容最大宽 720dp；横屏与平板居中，不用固定像素截断。
- 触控目标至少 48×48dp，正文至少 14sp，金额可随系统字号放大；文本缩放 200% 时允许
  换行和滚动，不遮挡保存/确认操作。
- 颜色不作为唯一状态信号；收入/支出同时使用文字和符号；重要图标提供语义标签。
- 加载、空、错误、离线、成功均有明确状态；AI/Telemetry 故障不阻塞本地记账。

## 游客与数据安全入口

页面固定显示“游客模式”：不登录也能完整本地记账；当前数据仅保存在本机；未来登录可用于
云备份和多设备同步，但当前没有注册、云备份或云同步。提供敏感后台预览保护说明和可选应用锁
入口；不得显示已经支持同步的误导状态。

## 明确非目标

本轮不实现注册、账单云同步、业务 Outbox、RAG、Agent、长期记忆、任意 SQL、生产部署、
年度视图或日预算。`IOS_TOOLCHAIN = BLOCKED`。
