# AI 隐私与降级说明

状态：P1D Rapid Upgrade 已实现
更新日期：2026-08-04

## 数据边界

月度总结、预算解读和规划只收到本地确定性计算后的最小聚合摘要。自由对话默认不带账本；
用户可逐项选择今日、本月和预算的聚合摘要。自然语言解析只发送用户主动输入的一句话、时区、
币种和允许分类名。截图理解只发送用户明确选择、经本地重编码去 EXIF 的单张图片。

除用户主动输入的自然语言和主动选择的截图外，禁止发送原始交易、备注、商户、姓名、手机号、
邮箱、设备 ID、精确地址、SQLite/业务 UUID、账号卡号、数据库文件、Key、Authorization、
Cookie、SQL、内部异常正文和模型推理。聊天附带上下文始终是聚合文本，不含原始账单。

## 确定性与 AI 的职责

| 本地确定性层 | AI 可选解释层 |
|---|---|
| Int64 最小货币单位金额 | 用自然中文解释趋势 |
| 收入、支出、净额 | 提炼可执行建议 |
| 预算、已用、剩余、超支 | 解释预算状态和风险 |
| 环比、日趋势、分类排行 | 给出一般性财务信息 |
| 财务目标月度缺口 | 不得重算或替换本地金额 |

AI 不能创建、修改或删除交易、账户、分类和预算，也不能承诺收益、下证券指令或给出法律、
税务、医疗诊断。系统提示词要求温柔、知性、甜美但克制：先肯定已有进展，避免责备和制造
焦虑，同时不得淡化超支、缺口和风险；不得展示 JSON 字段名或代码术语。

自然语言和截图识别只能生成 `needs_confirmation=true` 的独立草稿；服务端与 Flutter 均验证
结构，Flutter 还要映射到真实、启用且类型匹配的本地账户/分类。只有用户点击确认才写 Drift。
图片只在客户端预览和服务端内存中短暂存在，不写 PostgreSQL、日志、Telemetry 或聊天历史。

## 降级矩阵

| 场景 | Flutter 展示 | 本地数据 | 重试 |
|---|---|---|---|
| 离线/服务未启动 | 网络不可用/无法连接 | 完整保留 | 可重试 |
| 客户端或上游超时 | AI 请求超时 | 完整保留 | 可重试 |
| HTTP 429 | 请求过于频繁 | 完整保留 | 稍后重试 |
| Provider 禁用/未配置 | AI 当前未启用 | 完整保留 | 配置后重试 |
| JSON/Pydantic 无效 | AI 返回格式无效 | 完整保留 | 可重试 |
| 上游 5xx | AI 服务暂不可用 | 完整保留 | 受控重试 |
| production 无认证 | 拒绝生成 | 完整保留 | 不自动绕过 |

Flutter 在失败条上继续显示确定性摘要，并保留上一份成功解释（如有）；AI 故障不阻塞记账、
预算、统计、冷启动或数据库读写。

## 结构化输出与日志

- Kimi 使用严格 JSON Schema；对象禁止未知字段，文本和数组设上限。
- 结果再经过 Pydantic strict 校验；首次无效最多修复一次。
- 客户端只解析各场景白名单字段；自由对话、解析和图片结果都有独立严格模型。
- 日志只记录场景、模型、重试、延迟和 token 数；不记录请求/回复正文、Key 或推理。
- HTTP 错误统一映射为稳定错误码，不透传上游正文。

## 当前限制

支持当前进程内最多 8 轮的自由对话和单张 PNG/JPEG/WebP 财务图片理解，但不保存服务端聊天
历史或图片。不支持长期记忆、RAG、向量库、Tool Calling、联网搜索、AI 自动写账、真实用户
同步或公开生产服务。完整 iOS 工具链仍未就绪，`IOS_TOOLCHAIN = BLOCKED`。
